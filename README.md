# เสนาะสำเนียง By ครูนนท์

- ครูเพิ่มบทอ่านได้เองที่แท็บ "สำหรับครู" (กาพย์ กลอน โคลง ฉันท์ ร่าย)
- ข้อมูล: Firebase (senoh-samniang) · ไฟล์เสียง: Google Drive ผ่าน GAS (`gas/Code.gs`)
- รายละเอียดการออกแบบและสถานะงาน: `PLAN.md` · ทดสอบถดถอย: `tests/`
